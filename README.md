# 🩺 Health Voice AI

An AI-powered voice health screening assistant that allows users to speak about their health concerns and receive AI-generated responses through voice.

## 🚀 Live Demo

🌐 **Live App:** https://health-voice-ai.onrender.com/

🔗 **GitHub:** https://github.com/31Krishna/health-voice-ai

## ✨ Features

- 🎤 Voice-based health conversation
- 📝 Speech-to-text conversion
- 🤖 AI-powered health conversation
- 🔊 AI-generated voice responses
- 🩺 Basic health screening
- 📋 Health report generation
- 📱 Responsive interface
- ☁️ Fully deployed on Render

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- JavaScript
- CSS
- Browser MediaRecorder API

**Backend**
- Node.js
- Express.js
- Multer
- CORS
- dotenv

**AI**
- Sarvam AI
  - Speech-to-Text
  - AI Conversation
  - Text-to-Speech

**Deployment**
- GitHub
- Render
